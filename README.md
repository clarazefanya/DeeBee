# DeeBee

DeeBee is a story-driven SQL learning application built with Flutter. It combines structured learning content with interactive exercises to make learning SQL concepts more engaging and enjoyable.

## Features

- **Interactive Learning Modules**: Explore learning materials organized into modules, chapters, levels, and scenes.
- **Interactive Exercises**: Practice through three types of questions: multiple-choice, word arrangement, and SQL query writing.
- **XP System & Leaderboard**: Earn experience points (XP) and compare progress on the leaderboard.
- **Role-Based Access Control**: Provides different access permissions for regular users and administrators.
- **Content Management**: Administrators can manage learning modules, chapters, levels, scenes, and scene assets.

## Tech Stack

- **Framework:** Flutter
- **Programming Language:** Dart
- **Local Storage:** Shared Preferences, sqflite
- **Database:** Firebase Cloud Firestore
- **Authentication:** firebase_auth
- **Firebase Integration:** firebase_core

## Getting Started

### Prerequisites

- Flutter SDK 3.41.9 or a compatible version
- Dart SDK 3.11.5 or a compatible version
- Android Studio or Visual Studio Code
- A Firebase project configured for the application

### Installation

1. Clone this repository:

   ```bash
   git clone <https://github.com/clarazefanya/DeeBee>
   ```

2. Navigate to the project directory:

   ```bash
   cd deebee_user
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Configure Firebase for your development environment.

5. Run the application:

   ```bash
   flutter run
   ```
